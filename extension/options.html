media·hub

Extension options

Pair this extension with the Media Hub desktop app. Find the token in Media Hub: Settings → Browser bridge → Token.

Connection

Default is http://127.0.0.1:47821. Change only if you set a custom port in Media Hub's Settings.

64 hex characters. Copy it from Media Hub's Settings page.

How to use

  • Click the extension icon → Send to Media Hub. Pick Video / MP3 / M4A / FLAC, hit send.
  • Right-click any link, video, or page → Send to Media Hub (with format submenu).
  • App not running? The popup will show a "Try launching app" button that uses the mediahub:// deep-link to cold-start Media Hub with your URL already queued.
